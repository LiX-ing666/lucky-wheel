# 幸运大转盘抽奖工具

一个纯前端、单文件即可运行的抽奖大转盘，适合班会、年会、门店活动、课堂点名等现场场景。
所有数据（人名、奖品、历史记录、设置）都保存在浏览器本地（localStorage），不联网也能用。

> 当前版本：**v3.8.0（纯净版）**

---

## 一、功能概览

### 转盘与抽奖
- 彩色扇形转盘，点击开始旋转，再次点击进入减速，平滑停在中奖格
- 中心「抽奖」文字固定不随盘旋转（久看不晕）
- 转盘格数可切换：6 / 8 / 10 / 12 格
- 奖品名称、颜色可在后台自定义，支持 emoji
- 减速圈数可调（0～10 圈，设为 0 时点击暂停立刻停下）
- 转盘速度可调

### 人员管理
- 最多 60 人
- 单个添加、回车即添加
- 批量粘贴导入（一行一个名字）
- 文档导入：txt / csv / xlsx / xls（自动跳过表头、自动去重）
- 按姓名拼音首字母 A-Z 分组，左侧字母索引快速定位
- 人名按钮自适应宽度，完整显示全名不省略
- 最近使用人员快捷入口

### 抽奖记录与统计
- 右侧显示当前人员、已抽次数（不限次数，只做计数）
- 抽奖历史表格：人员、奖品、时间（含秒）
- 中奖统计：按奖品 / 按人员汇总，可显示柱状图
- 导出 CSV、打印记录
- 一键清空抽奖记录（二次确认）
- 切换人员时次数清零，但保留上一位人员的历史记录

### 后台管理（需密码）
- 默认密码：`123456789`（可在后台修改）
- 忘记密码：在登录弹窗标题上快速连点 5 次，确认后恢复默认密码
- 后台 Tab：奖品 / 方案 / 速度 / 趣味跳格 / 再来一次 / 气氛 / 音乐 / 背景 / 外观 / 功能 / 关于

### 个性化
- 背景：纯色 / 渐变 / 自定义图片
- 全站字号调节（80%～150%）
- 主界面文字颜色可调（标题 / 正文 / 次要说明）
- 中奖提示配色可调
- 多套奖品方案切换
- 背景音乐导入（mp3 / wav 等常见格式）
- 旋转滴答声、中奖音效
- 中奖庆祝特效（彩带礼花）

### 增强功能（均可开关）
- 「再来一次」模式：抽到指定奖品时累计一次机会，不计总次数，下次抽奖优先消耗
- 趣味跳格：抽中后再跳几格
- 麦克风气氛感应：现场欢呼时提高中奖概率（热度平滑上升、缓慢衰减）
- 随机选人按钮
- 大屏模式
- 低性能模式：关闭粒子特效、简化发光，适合旧电脑和投影仪
- 数据备份 / 恢复
- 离线单文件 HTML 导出（可拷到任何电脑双击打开）

### 受密码保护的工具（功能 Tab 进入）
- 加权概率工具：默认密码 `123456789`，可修改；支持逐格权重、恢复均等
- 一键清除数据：需密码 + 二次确认，可选「仅清历史统计」或「清空全部恢复出厂」

## 二、快速开始

### 方式一：在线使用
打开应用的在线访问链接即可（无需安装）。

### 方式二：离线单文件
1. 进入后台 → 功能 Tab → 「下载离线网页版」
2. 得到一份 HTML 文件，双击用浏览器打开即可
3. 离线版数据同样存在本机浏览器，换电脑需要重新录入或导入备份

## 三、使用流程（推荐）

1. 进后台录入奖品，按需要调整格数、速度、配色、背景、音乐
2. 录入人员名单（支持批量粘贴或导入文档）
3. 主界面左上角选人框中选中一位人员
4. 点击中心「抽奖」开始旋转，适当时候再次点击进入减速，停在中奖格
5. 系统自动记录该人员和奖品到历史表
6. 换下一位人员：点击另一位人员即可（次数清零，历史保留）
7. 活动结束：导出 CSV 或直接打印历史记录

## 五、常见问题

**Q：忘记后台密码怎么办？**
在登录弹窗标题上快速连点 5 次，确认重置，密码恢复为 `123456789`。之后建议在后台重新设置一个自己的密码。

**Q：换了浏览器 / 换了电脑，数据没了？**
数据存在浏览器本地。后台提供「数据备份」，可导出备份文件，在新环境「恢复」即可。

**Q：转盘上的字为什么是斜的 / 被拉伸？**
当前版本文字为水平横排、不随盘旋转。若显示异常，请刷新页面；仍有问题可在后台调整「转盘奖品文字大小」。

**Q：后台设置项太多，怎么快速开活动？**
最少只需三步：改奖品名 → 录人名 → 选人开抽。其余功能都可关闭。

**Q：现场投影仪卡顿怎么办？**
后台 → 功能 Tab → 打开「低性能模式」，会关闭粒子特效并简化发光。

- 支持 Windows / macOS / 手机端访问
- 离线版为单个 HTML 文件，可 U 盘拷贝、断网使用
